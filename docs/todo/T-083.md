## Concept
A UI-free Core service that extracts a normalized audio peak array from the loaded video (via ffmpeg to a temp
PCM file), with a cache, cancellation, and best-effort (never throws) semantics — the data source for the
scrub-bar waveform. Mirrors `IThumbnailService`/`FfmpegThumbnailService` (T-077).

## Design (from docs/design/D-002-audio-waveform.md § 4)
- **`IWaveformService` / `FfmpegWaveformService`** in `src/Core/` (near `Thumbnails/`): 
  `Task<float[]?> GetPeaksAsync(string inputPath, int buckets, CancellationToken ct)` → a normalized 0..1 peak
  array (max-abs amplitude per bucket), or `null` on any failure / no-audio (best-effort, catch → null, never throw).
- **Extraction:** ffmpeg decodes a **downsampled mono PCM** stream to a temp file (e.g. `-ac 1 -ar <low, ~1–8kHz>
  -f s16le` via `FfmpegArgs`), the service reads the Int16 samples and buckets them into `buckets` columns
  (max-abs per bucket) → normalized peaks. **Temp file, not piped** — `FfmpegRunner` reads stdout as UTF-8 text, so
  raw PCM must go through a temp file (same constraint as the thumbnail service).
- **No audio track** → ffmpeg produces no/empty PCM → return `null` (the App hides the band). Never an error.
- **Cache** the peak array keyed by `(inputPath | mtime | length)` (like the keyframe/thumbnail cache); bound it
  (LRU / few entries — a peak array is small). `Clear(inputPath)`/`ClearAll()` best-effort.
- Inject `IFfmpegRunner`/`IFfmpegBinaryLocator` like the split/thumbnail services; injectable temp root + a fake
  runner for tests. Keep Core UI-free (returns `float[]`, not a visual).

## Acceptance criteria + Case-Coverage Matrix
- [ ] `GetPeaksAsync` returns a normalized `float[buckets]` (values 0..1) for a video with audio; the ffmpeg args are mono + low-rate + s16le to a temp file.
- [ ] Same (path,mtime,length) twice → cache hit (runner not re-invoked) — assert via a fake runner's call count.
- [ ] No audio / ffmpeg failure / missing file → `null`, does NOT throw.
- [ ] Cancellation honored.
- [ ] `Clear`/`ClearAll` remove temp/cache; best-effort (missing → no-op).
- [ ] Core UI-free (`CoreIsUiFreeTests` green). Build 0-warning; suite green (baseline 544) + new service tests (fake `IFfmpegRunner`).
- Matrix — Success: peaks for audio video; cache hit. Boundary: no-audio → null; tiny buckets; very long video (downsampled, cheap); cancel mid-extract. Required-Fail: throws → not allowed (null).

## Dependencies
None (Core-only). Blocks T-084 (the UI consumes this).

## Risks
Binary-output pitfall avoided via temp file (don't pipe PCM through the UTF-8 stdout runner). Bucketing/normalization
correctness — unit-test with synthetic PCM. Keep extraction cheap (downsample).

## Out of scope
The waveform UI/TimelineView band (T-084); spectrogram; silence-detection.
