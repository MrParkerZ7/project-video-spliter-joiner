## Concept
Give the WindowChrome frame a clean themed border line (replacing the default system hairline that clashes with the dark theme) and open the app at a larger, centered default size suited to the two-column layout — without breaking maximize/restore, the taskbar clamp, or the resize border.

## Design
- **Border (D1):** wrap the root `Grid` (the one with `Margin="{... ContentMargin}"`) in a `Border` with `BorderThickness="1"`, `BorderBrush="{DynamicResource BorderStrongBrush}"`, `Background="{DynamicResource BgBrush}"`. Keep the existing `ContentMargin` binding on the inner Grid. **Maximized-state safety:** ensure the 1px border does not show as a floating line when maximized — either bind `BorderThickness` to 0 in the Maximized state (a small converter, or reuse the state the `ContentMargin` converter already switches on) OR confirm the maximized inset covers it. Verify by maximizing.
- **Startup size (D2):** on the `<Window>` — `Width="1280" Height="800"`, add `WindowStartupLocation="CenterScreen"`, bump `MinWidth="960" MinHeight="600"`. Keep `ResizeMode="CanResize"` and `WindowStyle="SingleBorderWindow"`.
- Leave the WindowChrome block, caption row, and the `WM_GETMINMAXINFO` clamp untouched.

## Acceptance criteria + Case-Coverage Matrix
- [ ] The window frame shows a themed 1px `BorderStrongBrush` line (not the default light system hairline).
- [ ] App opens at 1280x800, centered; resizable down to 960x600.
- [ ] Maximize → restore works; when maximized the border does NOT show a stray floating line; content isn't clipped and the taskbar isn't covered (the clamp still holds).
- [ ] The 6px resize border still resizes from all edges.
- [ ] Build 0-warning; existing tests green (this is XAML-only; the `WindowStateConverters` tests, if any, stay green — add a tiny test if you introduce a border-thickness converter).
- Matrix — Required-Success: normal window shows themed border + opens 1280x800 centered. Boundary: maximized (no stray line, no clip, taskbar visible); resized to min (960x600). Required-Fail: none.

## Dependencies
None. XAML-only in `MainWindow.xaml` (+ maybe a small converter in `WindowStateConverters.cs`).

## Risks
Stray border line when maximized (tie thickness to state). Don't touch the taskbar clamp / resize border.

## Out of scope
Rounded corners; caption-button restyle; DPI-specific tuning.
