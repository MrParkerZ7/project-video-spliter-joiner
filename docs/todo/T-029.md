## Concept
Round out the preview into a normal video player: a volume slider + mute toggle and a playback-speed control — the "fundamental options same as a video player app" part of the ask.

## Design
- **Extend `IMediaPlayer` (D2):** `double Volume {get;set}` (0..1), `bool IsMuted {get;set}`, `double SpeedRatio {get;set}` (e.g. 0.25..2.0, 1.0 = normal). `FfmeMediaPlayer` maps to FFME's `Volume`/`IsMuted`/`SpeedRatio` (verify member names from the DLL); `NullMediaPlayer` stores no-op defaults; the test fake stores them.
- **`PlayerViewModel`:** bindable `Volume` (double), `IsMuted` (bool, `MuteCommand` toggles), `SpeedRatio` (double) + a small set of speed presets (e.g. 0.25/0.5/1/1.5/2) for a dropdown, and `SpeedText`. Setting each writes through to the player.
- **UI (`PlayerView.xaml`):** add to the transport area — a **volume slider** (0–1) + a **mute** toggle button (icon/label reflects state), and a **speed** selector (ComboBox of presets, or −/+ with a readout). Keep compact; place sensibly with the T-028 skip row (e.g. skips on one line, volume+speed on the transport line with play/pause).

## Detail
- Mute toggles without losing the volume level (restore on unmute); volume slider reflects/controls level.
- Speed applies live (FFME `SpeedRatio`); default 1.0 on open.
- No split/join/marker change; purely preview playback options behind the seam.

## Interfaces / contracts
- `IMediaPlayer` gains `Volume`/`IsMuted`/`SpeedRatio` (update `FfmeMediaPlayer`, `NullMediaPlayer`, test fake). `PlayerViewModel` gains the bindable props/commands.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Setting `Volume` writes through to the player (fake records it); `MuteCommand` toggles `IsMuted` and restores the prior volume on unmute.
- [ ] Setting `SpeedRatio` (preset) writes through; default 1.0 after open.
- [ ] Build 0-warning; existing tests green (fake updated for the new members); new volume/mute/speed logic unit-tested.
- Matrix — Required-Success: volume/mute/speed each write through + reflect state. Boundary: volume 0 and 1; mute→unmute restores level; min/max speed preset. Required-Fail: n/a.

## Dependencies
T-028 (serialized — both edit `IMediaPlayer`/`FfmeMediaPlayer`/`PlayerView`/`PlayerViewModel` + the test fake).

## Risks

## Out of scope
