## Why / vision
Dragging the scrub pin should preview the video AS you drag, like any player. Today it doesn't — so the pin feels laggy/"delayed."

## Gap from current state (diagnosed, not guessed)
- `PlayerView.xaml.cs`: `OnScrubDragStarted → BeginUserScrub()` (sets `_isUserScrubbing=true`, which SUPPRESSES echoes) and `OnScrubDragCompleted → EndUserScrub(finalValue)` (seeks ONCE at the end). So during the drag **no seek happens** — the video is frozen under the finger and only jumps on release (T-033's seek-on-release, chosen to kill the pop-back).
- `FfmeMediaPlayer.Seek` is fire-and-forget via `Run()` (each call starts an async FFME seek). There's **no coalescing** — repeated seeks would queue and lag behind.

## Decisions
- **D1 · Live scrub during drag** — while `_isUserScrubbing`, seek the player toward the current drag position (a `DragDelta` handler, or watching the bound value during drag) so the frame follows the pin. FFME `ScrubbingEnabled` is already on (fast keyframe preview).
- **D2 · Coalesce seeks (the key anti-lag)** — never queue seeks. Track "a seek is in flight"; while one is running, store only the LATEST requested position; when it completes, if the latest target differs, issue ONE seek to it. So the player always seeks toward where the pin IS now, never through a backlog of stale positions. Needs a seek-completion signal (the T-033 `Seeked` event already exists).
- **D3 · Throttle** — cap live-scrub seeks to ~a sane rate (e.g. one per ~60–80ms) so a fast drag issues a handful of seeks, not hundreds. Combine with D2 (throttle + coalesce).
- **D4 · Keep pop-back protection** — the T-033 seek-target hold stays; live scrub feeds it the moving target. On release (`EndUserScrub`), a final exact seek to the released position.

## Risks
- Live seeking a non-keyframe-heavy codec can still be slowish per frame → coalescing + keyframe-scrub keeps it responsive (preview need not be frame-exact mid-drag; the final release seek is exact — and cuts keyframe-snap anyway).
- Don't reintroduce the pop-back (T-033) or a seek feedback loop — feed the hold, don't fight it.

## Out of scope
Thumbnail-strip scrubbing, audio scrub; frame-exact preview on every mid-drag pixel — later.
