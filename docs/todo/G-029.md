## Why / vision
The custom title bar's min/maximize/close buttons draw **Segoe MDL2 Assets** glyphs at **FontSize 10** — small, thin, and rounded/generic against the app's crisp IBM Plex mono, tight-radius dark+gold look. Replace them with hand-drawn vector icons that read as intentional and stay sharp everywhere.

## Grounding (2026-07-18)
- `MainWindow.xaml` caption row: `MinimizeButton` (`&#xE921;`), `MaxRestoreButton` (Content bound to `WindowStateToMaxRestoreGlyphConverter` → `` maximize / `` restore), `CloseButton` (`&#xE8BB;`). Styles `CaptionButton` / `CloseCaptionButton` in `Themes/Controls.xaml`.
- `CaptionButton`: 46×34, `FontFamily="Segoe MDL2 Assets"`, `FontSize=10`, `Foreground=TextPrimaryBrush`, hover `SurfaceHoverBrush` / pressed `SurfacePressedBrush`, `WindowChrome.IsHitTestVisibleInChrome=True`. `CloseCaptionButton` hovers `DangerBrush` (red).
- WindowChrome caption + the `WM_GETMINMAXINFO` clamp + maximized inset are separate and must stay intact.

## Decisions
- **D1 · Vector Path icons** — replace the font glyphs with crisp stroked `Path` geometry, centered in the 46×34 button: **minimize** = a 1px horizontal line (~10px wide); **maximize** = a square outline (~10×10, 1px stroke); **restore** = two offset overlapping squares; **close** = an X (two 1px diagonals). Stroke = `TextPrimaryBrush`, `StrokeThickness≈1`, with `SnapsToDevicePixels`/`UseLayoutRounding` + pixel-aligned coords for crisp 1px edges. Keep the 46×34 hit area + hit-test-in-chrome.
- **D2 · State-driven maximize/restore** — the middle button shows the **maximize square in Normal** and the **restore double-square in Maximized**. Drive via a `DataTrigger` on the window `WindowState` (swap the Path `Data`/visibility) or a value→Geometry converter — replacing the current glyph converter's role. Keep the existing maximized behavior/clamp.
- **D3 · Hover contrast** — min/max hover = `SurfaceHoverBrush` with the icon staying `TextPrimaryBrush` (or gold accent); **close** hover = `DangerBrush` red with the icon switching to a **light/white** stroke for contrast (a trigger swapping the Path stroke on the close button's hover).
- **D4 · Keep it in the styles** — implement as reusable icon content/templates so the three buttons stay consistent; retire the Segoe MDL2 `FontFamily` on these buttons (and the glyph converter if fully replaced) OR keep the converter returning geometry — either way no more font-glyph dependency for the caption.

## Risks
- Crisp 1px strokes across DPI — use pixel-aligned integer coords, `UseLayoutRounding`, `SnapsToDevicePixels`; test at 100% + 150%.
- The maximize↔restore swap must track `WindowState` (don't lose the restore icon when maximized).
- Don't break the caption drag, hit-test-in-chrome, the close/minimize/maximize actions, or the `WM_GETMINMAXINFO` clamp.

## Out of scope
