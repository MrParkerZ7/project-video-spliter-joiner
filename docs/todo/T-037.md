## Concept
The user couldn't copy the error to report it. Make the error fully copyable and keep the FULL log (not just the truncated tail).

## Design
- **Copyable UI:** in the error "details" area (Split + Join views + the OperationViewModel error surface), replace the non-selectable `TextBlock` with a read-only, selectable `TextBox` (`IsReadOnly=True`, `TextWrapping`, scroll) OR add a **"Copy" button** that copies the full error text to the clipboard (`Clipboard.SetText`). Prefer BOTH (selectable + a one-click Copy).
- **Full log, not a tail:** today `FfmpegResult.StdErrTail` keeps only the last ~N lines. For a failed op, write the FULL stderr to a per-run **log file** (`%LOCALAPPDATA%/VideoSplitJoiner/logs/<op>-<timestamp>.log`) and surface the log path in the error UI with an "Open log" / "Copy path" affordance. `UserFacingError` gains the log-file path.
- Keep the friendly headline + category (from `FfmpegErrorMapper`); the copyable detail is the full raw log + the path.

## Detail
- Clipboard access is WPF (`System.Windows.Clipboard`) — keep it in the view/code-behind or a tiny service; VM exposes the text + log path.
- The log dir is created on demand; a simple cap (keep last N logs) is nice-to-have (out of scope if it adds risk).
- Works for split, join, and detect-less load errors alike (shared OperationViewModel).

## Acceptance criteria + Case-Coverage Matrix
- [ ] The error details are selectable AND a Copy button copies the full error text to the clipboard.
- [ ] The FULL ffmpeg stderr (not just the tail) is written to a timestamped log file; its path is shown + openable.
- [ ] `UserFacingError` carries the full log / log path; unit-test the mapping keeps the headline + exposes the full text/path.
- [ ] Build + tests green.
- Matrix — Required-Success: a failed split → copyable full error + log file written. Boundary: very long log (scrolls, still copyable); empty stderr (graceful). Required-Fail: clipboard/log-write failure → don't crash, degrade gracefully.

## Dependencies
None (builds on the existing error path). Benefits from T-036 (so the copied log is UTF-8-correct).

## Risks
Clipboard/file-IO exceptions → wrap defensively. Log growth → simple cap.

## Out of scope
A full log viewer; telemetry; docs (T-039).
