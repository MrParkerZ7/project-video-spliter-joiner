## Concept
After fixing the add-cut regression (T-064), walk EVERY interactive action in the app and confirm it behaves exactly as before the T-059 two-column relayout. Fix any other migration regressions found. The relayout must be behavior-neutral.

## Checklist (verify each in a real app-run; fix any that fail)
**Split screen**
- [ ] Load via file picker (opens at last input folder); drag-drop a file onto the screen
- [ ] Add marker via the field; Set cut point at playhead; timeline click-to-add; click a marker tick to seek
- [ ] Remove a marker; markers snap to keyframes; optimistic add while indexing (T-041)
- [ ] Parts-to-export: All / None chips + individual checkboxes; Run label reflects the selection ("Split 2 of 3 parts")
- [ ] Output DIR defaults to the loaded file's folder + re-anchors on new load (G-020); NAME editable; Open folder
- [ ] Run split (progress + staged status + ETA); Cancel mid-run; Clear resets the screen (blank preview, markers/output cleared)
**Player controls**
- [ ] Play / Pause / Stop; scrub (live-scrub follows the pin, no pop-back — T-033/T-051)
- [ ] Skips ±1s/5s/10s/20s/1m/5m/10m/20m; frame-step; volume; mute; playback speed
- [ ] Position/duration readout updates live; resizable video pane divider (G-006) still drags
**Join screen**
- [ ] Add clips (picker + drag-drop); reorder; remove; Clear all
- [ ] Overwrite-existing toggle; output FILE editable; Estimated result panel (total duration + approx size) computes from probed clips
- [ ] Run join (progress/status/ETA); compatibility banner shows for mismatched clips
**Cross-cutting**
- [ ] Two-column splitter drags on both screens; empty-state placeholders show with no file; window chrome (min/max/close, taskbar clamp) intact
- [ ] Copyable error + Open log on a forced failure (Split + Join)

## Acceptance criteria
- [ ] Every checklist item verified in a live app-run with a real file; each pass/fail recorded.
- [ ] Any action that regressed vs pre-T-059 is fixed at the true layer (binding/re-parent issue, not a behavior change).
- [ ] Full suite green; build 0-warning; final app-run confirms the app is usable end-to-end.

## Dependencies
T-064 (the add-cut fix) first.

## Risks
Requires manual/live verification (headless can't render); be systematic — a checklist item skipped is a regression shipped. Log anything skipped.

## Out of scope
New features; visual polish beyond parity; the flaky-test diagnosis (G-021).
