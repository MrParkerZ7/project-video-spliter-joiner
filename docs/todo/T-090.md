## Concept
Implement D-003 in `SplitView.xaml`: (1) Position onto the "Add cut at playhead" line; (2) Cut markers +
Parts-to-export split the tool-panel height 50/50 (stacked star-rows, Parts full-width).

## Design (from docs/design/D-003-split-panel-5050.md, D1–D6)
1. **Add-cut + Position on one row** — the Cut-markers section's first row = a horizontal group **`[Add cut at
   playhead]` · `POSITION` label · time `TextBox` (`NewMarkerPosition`) · `[Add at time]` (`AddMarkerCommand`)**.
   Use a `WrapPanel` so it wraps at the ~360px narrow horizontal width and stays single-line when roomy (vertical mode).
2. **Tool-panel container → bounded 50/50 star Grid (D5).** The tool panel is currently `Border→ScrollViewer→
   StackPanel`. Replace with a bounded **`Grid`** (drop the outer ScrollViewer — it defeats star-sizing) whose rows are:
   file-info card `Auto` · keyframe warning `Auto` · Cut-markers header+add-row `Auto` · **marker `ListBox` `*`** ·
   Parts-to-export header `Auto` · **segments `ListBox` `*`** · Output `Auto` · Run/progress `Auto`. The two `*` rows
   (the two lists) split the leftover height **50/50**; each `ListBox` scrolls **internally**. The Grid fills the
   tool-panel region (the `OrientedSplitPanel.SecondChild`, which is bounded in both modes).
3. **Parts full-width (D4)** — remove the T-089 2-column Position|Parts Grid; Parts is now the full-width bottom
   section (header + All/None chips + segments list), under the marker list.
4. **Short-window fallback (D6)** — each list `MinHeight` (~90) + internal scroll; the Run button must always be
   reachable. If the bounded Grid can't fit everything on a very short window, wrap it in a ScrollViewer that only
   engages below the min (last resort) — try the plain bounded Grid first.
- **Re-parent, do NOT rewire** — `SetCutAtPlayheadCommand`, `NewMarkerPosition`+`AddMarkerCommand`, `SelectAll/
  NoSegmentsCommand`, per-part `IsSelected`, `SeekToMarkerCommand`/`RemoveMarkerCommand`, `SelectedSegmentCount`,
  per-part progress — all intact. Don't touch the OrientedSplitPanel/D-001, the video region/waveform, Load/Clear (tab line), or Output/Run logic.

- [ ] "Add cut at playhead" + the POSITION field + "Add at time" render on one line (wrapping when narrow).
- [ ] The Cut-markers list and the Parts list each take ~50% of the tool-panel height and scroll internally when overflowing.
- [ ] Parts to export is full-width below the markers.
- [ ] Every control works; Run button always reachable; usable at ~300px min width; roomy + correct in D-001 vertical mode.
- [ ] Build 0-warning; suite green (baseline 593 — layout-only; VM tests stay green).
