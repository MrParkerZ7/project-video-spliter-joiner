## Why

User: *"on bulk cut I also want button delete all selected, target is to remove all original file to save
more space, it should available only when bulk cut process done"*

Trimming a folder of episodes leaves the originals beside the `_trimmed` outputs — roughly double the
space, which is the whole reason for asking.

This deletes the user's video files, so the goal is mostly about what it refuses to do: only rows the
batch actually finished, only when the trimmed file is on disk **at press time** (the run may be minutes
old), never when the output *is* the original, always to the Recycle Bin, always behind a counted
confirmation that defaults to No.

## Out of scope
Deleting outputs. Undo beyond the Recycle Bin. Any automatic deletion.
