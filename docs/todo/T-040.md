## Concept
Add back/forward 10-minute and 20-minute skip buttons to the player jog row. UI-only — the skip command already accepts any seconds value and clamps.

## Design
- In `src/App/Views/PlayerView.xaml`, add four buttons to the existing jog `WrapPanel` (the same style/tooltip pattern as the current skip buttons), bound to the existing parameterized `SkipCommand`:
  - `-20m` → `CommandParameter="-1200"`, `-10m` → `"-600"` (place with the other back-skips, largest outermost)
  - `+10m` → `"600"`, `+20m` → `"1200"` (with the forward-skips)
- Tooltips e.g. "back 20 minutes" / "forward 10 minutes". Compact labels ("−20m"/"+10m"). No VM change — `SkipBy` (in `PlayerViewModel`) already clamps any delta to `0..Duration`.

## Detail
- Match the existing `JogButton` style + guard (buttons disabled when not `IsReady`, via the existing command's CanExecute).
- Row order suggestion: `|◄  −20m −10m −5m −1m −20s −10s −5s −1s  ⏴f  ▶  f⏵  +1s +5s +10s +20s +1m +5m +10m +20m  ►|` (wraps at small widths).

## Acceptance criteria + Case-Coverage Matrix
- [ ] The jog row shows ±10m and ±20m buttons; clicking seeks by ±600s / ±1200s (clamped) — verify via the existing `SkipBy` behavior (a unit test for `SkipBy(600)`/`SkipBy(-1200)` clamping if not already covered).
- [ ] Buttons disabled until a file is loaded/ready (existing CanExecute).
- [ ] Build 0-warning; prior tests green.
- Matrix — Required-Success: +10m from 2:00 → 12:00; +20m past end → clamps to end; −20m from 5:00 → 0. Boundary: near start/end clamps.

## Dependencies
None (extends the T-028 jog row).
