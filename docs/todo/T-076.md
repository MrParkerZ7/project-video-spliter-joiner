## Concept
Replace the small Segoe MDL2 font glyphs on the top-right caption buttons with crisp, theme-colored vector Path icons, state-driven maximize↔restore, with clear hover states — without breaking any window action or the taskbar clamp.

## Design
- **Icons (vector `Path`, centered in the 46×34 button, 1px stroke, pixel-aligned + `UseLayoutRounding`/`SnapsToDevicePixels` for crisp edges):**
  - **Minimize** — one horizontal line (~10px).
  - **Maximize** — a 10×10 square outline.
  - **Restore** — two offset overlapping squares (shown when `WindowState=Maximized`).
  - **Close** — an X (two diagonals).
  - Stroke = `TextPrimaryBrush`.
- **State swap (`MainWindow.xaml` / style):** the middle button shows maximize in Normal, restore in Maximized — via a `DataTrigger` on the window `WindowState` swapping the Path geometry/visibility (replaces the `WindowStateToMaxRestoreGlyphConverter` glyph role; keep or retire the converter accordingly).
- **Hover:** min/max → `SurfaceHoverBrush` bg, icon stays `TextPrimaryBrush`; **close** → `DangerBrush` bg with the icon stroke switching to a **light/white** brush for contrast (trigger on the close button template).
- Put the icon geometry in the button `Content`/templates in `Themes/Controls.xaml` (or `MainWindow.xaml`) so the three stay consistent; drop `FontFamily="Segoe MDL2 Assets"` from the caption button styles once glyphs are gone.
- Keep 46×34 size, `WindowChrome.IsHitTestVisibleInChrome=True`, the click handlers (`Minimize_Click`/`MaxRestore_Click`/`Close_Click`), and the `WM_GETMINMAXINFO` clamp untouched.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Minimize / maximize / restore / close render as crisp vector icons (no Segoe MDL2 glyphs), theme-colored, sharp at 100% and 150% DPI.
- [ ] The middle button shows a maximize square when Normal and a restore double-square when Maximized (swaps live on state change).
- [ ] Hover: min/max show the neutral hover bg; close shows red with a light icon.
- [ ] All three actions still work (minimize, maximize↔restore toggle, close); caption drag + hit-test-in-chrome intact; maximize doesn't cover the taskbar (clamp holds).
- [ ] Build 0-warning; suite green (XAML/converter change — if the glyph converter is retired, drop its now-dead test or repoint it; if a geometry converter is added, a tiny unit test is fine).
- Matrix — Required-Success: icons crisp + actions work. Boundary: maximized (restore icon shows; no clip; taskbar visible), 150% DPI (still crisp), close hover (red + light icon). Required-Fail: none. (Exact look = app-run/user-verified.)

## Dependencies
None.

## Risks
1px crispness across DPI; the max↔restore state swap; not regressing window actions / clamp / drag.

## Out of scope
Rounded corners; animation; other buttons.
