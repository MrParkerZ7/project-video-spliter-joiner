## Why / vision
For long videos, 5m is the biggest jump — reaching a point 30–40 min in takes many clicks. 10m and 20m skips make coarse navigation fast.

## Gap from current state
`PlayerView.xaml` jog row (T-028) has skip buttons for ±1s/5s/10s/20s/1m/5m, bound to a parameterized `SkipCommand` (CommandParameter = seconds; `SkipBy` clamps to the clip). Missing: ±10m (600s) and ±20m (1200s).

## Decisions
- **D1 · UI-only** — add four buttons (`-20m -10m … +10m +20m`) with `CommandParameter="-1200"/"-600"/"600"/"1200"` to the existing jog `WrapPanel`. `SkipBy` already handles any delta + clamps, so NO VM/logic change. Keep the row readable (it wraps).
