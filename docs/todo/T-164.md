## Concept

Document the surfaces G-052 added to the Split screen, so the epic is not "done" while the docs still
describe a Split that cannot reclaim anything. Terminal node of the epic — runs only after
[[T-162]] and [[T-163]] land.

## Acceptance criteria
- [ ] **USER_GUIDE** — the Split screen gains the delete-original gesture and the two automatic options,
      in the same voice the Bulk Cut section uses, including the plain statement that emptying the bin is
      whole-bin and permanent.
- [ ] **CHANGELOG** `[Unreleased]` — user-facing outcomes, not commit subjects.
- [ ] **SPEC-010** — invariants for the eligibility rule (all parts present), the deletion-time re-check,
      the Recycle-Bin-not-permanent guarantee, and each of the four arming gates; `docs/specs/_index.md`
      recounted **mechanically** and the freshness guard green.
- [ ] **ARCHITECTURE** — Split's use of `IOriginalDisposer` / `ShellRecycleBin`, and whatever shared
      extraction T-162 chose (or its recorded decision not to extract).
- [ ] **ADR** only if T-162/T-163 made a decision with a rejected alternative worth recording — e.g. the
      shared-vs-duplicated deletion path. No ADR if neither did; do not manufacture one.
- [ ] Any claim written is checked against the code, not the ticket. T-154 shipped a spec invariant
      (I122) asserting behaviour the DragOver gate made unreachable, and it survived a whole ticket.

## Out of scope
