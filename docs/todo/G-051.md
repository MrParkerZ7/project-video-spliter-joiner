## Why

User: *"for profile setting please make sure setting was saved and restore able even after reinstall app
again"*

Checked before planning. Uninstall already leaves them alone — the Inno script has no `[UninstallDelete]`
— but that is an accident of the current script rather than a guarantee, and nothing would catch a future
edit that started deleting user data.

The sharper problem is that a profile lives in **two different roots**: the profile itself in Roaming
`%APPDATA%`, its picture in Local `%LOCALAPPDATA%`. Back up "settings" and you keep the profiles and lose
every image, with the `ThumbnailPath` left pointing at a folder that does not exist. And there is no
export/import, so "restorable" today means copying two folders by hand.

## Out of scope
Cloud sync. Sharing profiles between users.
