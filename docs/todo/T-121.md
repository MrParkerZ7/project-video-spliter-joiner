## Concept
Add the option surface for writing the trimmed result over the ORIGINAL input, as a **separate orthogonal
axis** from collision policy. `CollisionPolicy` answers *"what if the destination is taken?"*;
overwrite-original answers *"which destination?"*. Folding it into `CollisionPolicy` would make
`ResolveCollision` return the SOURCE under an enum whose own header states *"The source file is NEVER a write
target under any policy"*, falsifying SPEC-002 I22. As its own axis that invariant survives — rescoped to
`OutputMode.NewFile` — and the relaxation lives in one named branch no existing caller can reach.

## Design
- NEW `src/Core/Bulk/OutputMode.cs`: `enum OutputMode { NewFile, ReplaceOriginal }`.
- Widen `BulkTrimOptions` (`:8`) to `(CollisionPolicy Collision = AutoSuffix, OutputMode Output = NewFile)` —
  exactly the "future knobs without breaking callers" its own comment anticipates; every call site still compiles.
- `BulkTrimEngine.cs:69` — pass the whole `opts` to `ResolveCollision`; add ONE early branch before the
  existing switch returning `(inputFull, overwrite: true, skip: false)` for `ReplaceOriginal`.
- The two `PathsEqual(desiredFull, inputFull)` force-AutoSuffix branches (`:218-221`, `:226-229`) and both
  source-refusals inside `ResolveAutoSuffix` (`:248`, `:260`) stay **byte-identical** and fully live for `NewFile`.
- Precedence documented + enforced: `ReplaceOriginal` wins, `Collision` is ignored (the destination is always
  taken, by the source itself). `DesiredOutputPath` is ignored in this mode — no VM path change needed.
- Rescope the now-narrower doc contracts: `BulkTrimItem.cs:9`/`:12-15`, `CollisionPolicy.cs:5-7`.

## Acceptance criteria + Case-Coverage Matrix
- [ ] `OutputMode.NewFile` (default) → every existing behaviour byte-identical; all current tests green untouched.
- [ ] `ReplaceOriginal` → the resolved effective path IS the input path, with overwrite=true and skip=false.
- [ ] The source-safety guard is NOT weakened for `NewFile` — a desired path equal to the source still force-AutoSuffixes.
- [ ] Disk pre-flight deliberately unchanged (temp and original coexist at peak).
- Matrix — Required-Success: both modes resolve correctly. Boundary: desired==source under NewFile,
  case/separator-different source path, ReplaceOriginal combined with each CollisionPolicy value (all ignored
  identically). **Perf (bounded heavy-op): resolution is pure path math — assert ZERO engine/probe calls during resolve.**
