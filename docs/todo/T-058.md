## Concept
Update the G-017 tokens to the sample's exact visual language: bundle IBM Plex Mono + Plex Sans, the full dark-surface + text + semantic + gold color scale, and the tight (6–12px) radii + dense type scale.

## Design
- **Fonts (bundle):** download **IBM Plex Mono** + **IBM Plex Sans** (OFL, from github.com/IBM/plex or Google Fonts) as `.ttf`; add under `src/App/Fonts/` with `Build Action = Resource`; expose `AppFontFamily` = `pack://application:,,,/Fonts/#IBM Plex Sans` and a new `MonoFontFamily` = `.../#IBM Plex Mono`. Add IBM Plex OFL attribution to `THIRD-PARTY-NOTICES.md`.
- **`Tokens.xaml` palette** — replace/extend to the extracted set: surface scale `Bg #0d0f13`, `SurfaceBrush #15181e`, add `Surface0 #0a0b0d`, `Surface1 #101215`, `Surface3 #1c2028`, `Surface4 #232935`; borders `BorderBrush #2a2e37`, `BorderStrongBrush #3a4250`; text `TextPrimaryBrush #eef0f3`, `TextSecondaryBrush #9aa0ab`, `TextMutedBrush #767c88`; accent `AccentBrush #e0a83a`, `AccentHoverBrush #f0bc55`; semantic `OkBrush #5fcf8e`, `InfoBrush #5b9cf0`, `AccentAltBrush #c77dff`, keep `DangerBrush`.
- **Radii:** `RadiusSm=6`, `RadiusMd=8`, `RadiusLg=12` (retighten from 8/12/24). **Type:** `FontSizeTitle=16`, `FontSizeBody=13`, `FontSizeSmall=11`, `FontSizeMicro=9`; default control font → mono where the sample uses mono (labels/values), sans for headings.
- **`Controls.xaml`** — update the base styles to use the new fonts (mono for labels/readouts) + tighter radii; keep the themed templates from G-017, just retune the token references + font.

## Detail
- Keep the app building + launching; a font that fails to resolve should fall back gracefully (add a system fallback in the FontFamily string).
- No layout change here (that's T-059) — this is tokens + fonts only.
