## Concept
Show the loaded video inside the app with real transport (play/pause/stop) and a scrubbable timeline, behind a testable `IMediaPlayer` abstraction so the ViewModel logic is unit-testable without rendering.

## Design
- `IMediaPlayer` (App) — `TimeSpan Position {get;set}`, `TimeSpan? Duration`, `bool IsPlaying`, `void Play()/Pause()/Stop()`, `void Open(string path)`, `void Seek(TimeSpan)`; events `PositionChanged`, `DurationAvailable`, `Ended`, `Failed(string reason)`.
- `MediaElementPlayer : IMediaPlayer` — wraps a WPF `MediaElement` (`LoadedBehavior=Manual`, `ScrubbingEnabled=true`). Polls Position via a `DispatcherTimer` (~200ms) → raises `PositionChanged`; maps `MediaOpened`→DurationAvailable, `MediaEnded`→Ended, `MediaFailed`→Failed. The MediaElement itself lives in the View; the impl holds a reference passed from the View.
- `PlayerViewModel : ObservableObject` — `Position`, `Duration`, `IsPlaying`, `PositionText`/`DurationText`, `PlayPauseCommand`, `StopCommand`, and a `Scrub(TimeSpan)` that seeks. Subscribes to IMediaPlayer events. Two-way `Position` binding drives the seek slider (setting Position from the slider = seek; playback updates it).
- `PlayerView` (UserControl) — the `MediaElement`, a play/pause toggle, stop, a `Slider` (0..Duration) bound to Position with drag→seek, and current/total time labels. A "preview unavailable" banner on `Failed` (per D1 fallback — cut still works).

## Detail
- Slider scrubbing: while the user drags, pause position-updates from the timer (avoid feedback), seek on release (or live with ScrubbingEnabled). Handle Duration not-yet-known (disable transport until `DurationAvailable`).
- `Open(path)` called when the Split screen loads a file (wire in T-013; here just expose it).
- Integrate `PlayerView` into `SplitView` (above the marker area, shown when a file is loaded). Keep the existing split flow intact.
- MediaElement needs the View's element; use a small attached-behavior or code-behind hand-off to give `MediaElementPlayer` the element reference (keep VM WPF-free).

## Interfaces / contracts
- Produces: `IMediaPlayer`, `MediaElementPlayer`, `PlayerViewModel`, `PlayerView` — consumed by T-013 (cut-from-playhead) + T-014 (timeline overlay).
- Contract: `PlayerViewModel` depends only on `IMediaPlayer` (fake-injectable).

## Acceptance criteria + Case-Coverage Matrix
- [ ] PlayerViewModel over a FAKE IMediaPlayer: PlayPause toggles IsPlaying + calls Play/Pause; Stop resets; DurationAvailable sets Duration + enables transport; PositionChanged updates Position/PositionText; Ended resets IsPlaying; Failed surfaces the banner flag.
- [ ] Scrub(t) seeks the player (fake records Seek(t)); setting Position from the binding seeks.
- [ ] PlayerView compiles; wired into SplitView without breaking existing SplitViewModel tests.
- [ ] Existing 162 tests stay green.
- Matrix (action coverage): every transport control (play, pause, stop, scrub) has a VM test. Required-Fail: transport disabled before DurationAvailable; MediaFailed → banner + no crash. Boundary: seek to 0 / to Duration / past Duration (clamp); zero-duration/failed open.

## Edge cases
Open failure (unsupported codec → Failed banner, cut still works); duration not yet known; seek past end; rapid play/pause; file replaced (re-Open resets).

MediaElement not testable headless (D2) → all real playback deferred to `app-run`; VM fully faked. Slider/timer feedback loop → guard during drag.

## Out of scope
