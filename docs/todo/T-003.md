## Concept
Read the truth about a media file so every downstream feature can make correct, no-re-encode decisions: how long it is, what codecs/streams it carries (for join compatibility), and — critically for keyframe-snap — WHERE the keyframes are.

## Design
- `IMediaProbe` / `MediaProbe` in `Core/Media`, built on `IFfprobeRunner` (T-002).
- `ProbeAsync(path)` → `MediaInfo { Duration, Container, VideoStreams[], AudioStreams[] }` from `ffprobe -show_streams -show_format -print_format json`.
- `GetKeyframesAsync(path)` → sorted `IReadOnlyList<TimeSpan>` of keyframe timestamps, via `ffprobe -skip_frame nokey -show_entries frame=pkt_pts_time` (or `-show_frames` with `key_frame=1` filter). Cached per-file.
- A `SnapToNearestKeyframe(TimeSpan requested)` helper (used by T-004 split) returning the actual snapped time + delta.

## Detail
- `StreamInfo { Index, CodecName, Type, Width, Height, PixFmt, SampleRate, Channels, TimeBase }` — the fields T-005 needs for a join-compat check.
- Keyframe scan can be slow on long files → run async with progress + cache the result keyed by path+mtime+size.
- Expose keyframe density (avg GOP seconds) so the UI can warn when snapping will be coarse.

## Interfaces / contracts
- Produces: `MediaInfo`, `StreamInfo`, keyframe list + `SnapToNearestKeyframe`. Consumed by T-004 (snap), T-005 (compat), T-006 (map detected times → nearest keyframe), T-007 (show info/warnings).
- Contract: probing a non-media/corrupt file returns a typed `ProbeFailed` result, never throws raw.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Correct duration + codec list for mp4/mkv/mov fixtures.
- [ ] Keyframe list is sorted, starts at/near 0, count matches a known fixture.
- [ ] `SnapToNearestKeyframe` returns the nearest keyframe + signed delta; picks correctly at midpoints and at file ends.
- Matrix — Required-Success: valid file → full MediaInfo + keyframes. Required-Fail: corrupt/non-media → typed ProbeFailed; zero video streams → handled (audio-only refused by callers). Boundary: single-keyframe file (all-copy), file whose only keyframe is at 0, request beyond duration (clamp to last keyframe).

## Edge cases
Audio-only file; variable frame rate; file with exactly one keyframe; request time past EOF; huge file (keyframe scan time).

## Dependencies
T-002 (ffprobe runner).

## Risks
Keyframe scan slow/memory-heavy on multi-GB files. Mitigation: stream the ffprobe output, don't buffer all frames; cache.

## Out of scope
Any cutting/joining; detection filters (T-006).
