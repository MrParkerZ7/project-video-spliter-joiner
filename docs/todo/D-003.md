## Concept
Refine the Split tool panel again (after reviewing T-089):
1. **Position** (the POSITION add-at-time field + "Add at time") moves **onto the same line as the "Add cut at
   playhead" button**, inside the Cut markers section.
2. **Cut markers** section and **Parts to export** section **share the vertical space 50/50** — stacked, each
   ~half the panel height (Parts returns to full-width, no longer a side column).

## Current state (T-089, verified)
Tool panel = `ScrollViewer → StackPanel`: file-info card · keyframe warning · **Cut markers** (header +
"Add cut at playhead" + marker list, full width) · a **2-column Grid** (Position | Parts to export) · Output · Run.

## Target (see design doc for the sketch + decisions)
Cut markers (header + [Add-cut-at-playhead · Position field · Add-at-time] on one row + marker list) taking the
TOP 50%, and Parts to export (full width) the BOTTOM 50% — the two list sections splitting the available height.

Full model: **[docs/design/D-003-split-panel-5050.md](../design/D-003-split-panel-5050.md)**.

## Out of scope
Output/Run sections; Load/Clear (on the tab line, T-088); the waveform/timeline; new controls.
