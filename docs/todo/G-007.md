## Why / vision
To pick a precise split point you need to move around the video the way a real player lets you: jump back/forward by set amounts, step a frame at a time, and control volume/speed. Today the player has only play/pause/stop + a scrub slider. Add the standard transport toolset — the skip buttons are the headline (find the perfect cut), the volume/speed/frame-step round it out to "feels like a video player."

## Gap from current state
`PlayerViewModel` exposes play/pause/stop + `Scrub` + Position/Duration/time text. Missing: relative skip (±N), frame-step, jump-to-ends, volume, mute, playback speed. `IMediaPlayer` has no volume/speed/step; `FfmeMediaPlayer` doesn't map FFME's `Volume`/`IsMuted`/`SpeedRatio`/`StepForward`/`StepBackward` yet.

## Decisions
- **D1 · Skip = relative seek, VM-only** — `SkipBy(TimeSpan delta)` = `Scrub(Clamp(Position + delta))`. No `IMediaPlayer` change for the second-based jog; pure `PlayerViewModel` over the existing `Seek`. Increments: 1s, 5s, 10s, 20s, 1m, 5m each direction + jump-to-start/end.
- **D2 · Frame-step + volume/mute/speed extend `IMediaPlayer`** — add `StepFrame(int dir)`, `Volume`, `IsMuted`, `SpeedRatio`. `FfmeMediaPlayer` maps to FFME (`StepForward`/`StepBackward`, `Volume`, `IsMuted`, `SpeedRatio`); `NullMediaPlayer` no-ops; the test fake stores/records them. `PlayerViewModel`/`SplitViewModel` gain bindable props but the split/join/marker contracts are untouched.
- **D3 · Fundamental set only** — volume+mute, speed, frame-step, skips. **Parked:** fullscreen / pop-out video, loop, A-B repeat.
- **D4 · Docs fold into the pending finalization (T-026).**

## Risks
- FFME frame-step / speed API is beta — verify member names from the DLL (like T-020/T-024); wrap defensively.
- Button-row crowding in the transport area → group skips compactly (a −/+ cluster) so the pane stays clean at small sizes.
- Live behavior (does frame-step/skip actually move the FFME playhead) only verifiable via app-run.

## Out of scope
Fullscreen/pop-out, loop/A-B repeat, keyboard shortcuts (could follow), audio-track selection.
