## Concept
Document the G-037 additions to Bulk Cut: the mini preview player + jog controls + set-at-playhead, and the reusable cut
profiles. Docs only — write against the shipped feature.

## Design
1. **`docs/USER_GUIDE.md`** — extend the Bulk Cut section: select a row → preview pane plays it; use the jog buttons
   (±1s/5s/10s/20s/1m) + timing bar to reach the exact intro end / outro start, then **Set intro-end here / Set outro-start
   here**; and the **cut profiles** flow (Save current as… → Apply → selected / all; same-series in one click; profiles
   persist). Note apply re-snaps + re-validates per file (a profile valid on a long episode may be flagged on a short one).
2. **`docs/ARCHITECTURE.md`** — a short note: the shared single-decoder preview player (SelectedItem + one PlayerViewModel,
   MediaReopenGuard on switch), reuse of PlayerView/TimelineView/SkipCommand, and the CutProfile model in AppSettings.
3. **`CHANGELOG.md`** — an entry under Unreleased: "Bulk Cut — preview player, jog controls, and reusable cut profiles (G-037)".
4. **ADR** — only if the profile persistence or the single-shared-player decision warrants one (optional; a short ADR on
   "one shared preview player bound to the selected row, not per-row" is reasonable).
