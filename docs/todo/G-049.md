## Why

User: *"the app should remember last use feature tab & horizontal/vertical alignment"*

Checked before planning, and it is half done. The **layout axis is already persisted** (`LayoutMode`,
D-001/T-081 — written on toggle, restored on startup, and visible in the settings file today). The
**tab is not**: `SelectedTabIndex` is in-memory only, so every launch starts on Split.

There is a live reason the persisted half may still *feel* broken: **T-140** — running the test suite
overwrites the user's real settings file, which would wipe the saved layout along with everything else.
Worth fixing before concluding that persistence is unreliable.

## Out of scope
Remembering loaded files or cut points — window state, not session state.
