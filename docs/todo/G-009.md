## Why / vision
Scrubbing to a spot and having the playhead snap back to a different position makes the preview unusable for finding a cut point — the whole reason the player exists. Must be rock-solid: where you drop the playhead is where it stays.

## Gap from current state (diagnosed, not guessed)
`PlayerViewModel` (src/App/ViewModels/PlayerViewModel.cs):
- L65–78: a user set of `Position` (slider TwoWay-bound to `PositionSeconds`) calls `_player.Seek(T)` — **async in FFME** (`Seek` returns a Task).
- L358 `OnPositionChanged` → `SetPositionFromPlayer(_player.Position)` sets `Position` to the player's CURRENT position under `_suppressSeek`.
- **The bug:** while the async seek to T is in flight (and/or playback is advancing), `PositionChanged` fires with the stale/current position P and **overwrites the slider back to P** — the pop-back. `_suppressSeek` only prevents a re-seek; it does NOT stop the display from being dragged off the target.

## Decisions
- **D1 · Hold the target during an in-flight seek** — when the user seeks to T (slider set, `Scrub`, skip, jump), record a `_seekTarget`/`_seeking` state and **ignore `PositionChanged` echoes until the actual position settles at ~T** (within a small tolerance) OR the FFME seek Task completes — then resume normal echo from the new position. This keeps the slider pinned to where the user dropped it.
- **D2 · Gate on active drag** — while the user is physically dragging the slider thumb, suppress position echoes entirely; apply the seek continuously (live scrub) or on release, then hold until settled. Use the WPF `Thumb.DragStarted`/`DragCompleted` (or a bound `IsUserScrubbing`) in `PlayerView`.
- **D3 · Prefer FFME seek-completion signal** — if FFME exposes seek start/finish (`SeekingStarted`/`SeekingFinished`) or the `Seek` Task, use it to clear `_seeking` deterministically (more robust than tolerance-matching); fall back to tolerance if not available.
- **D4 · Keep the seam** — fix lives in `PlayerViewModel` (+ a little `PlayerView` drag gating + maybe `FfmeMediaPlayer` seek-completion) behind the unchanged `IMediaPlayer`; VM stays unit-testable with the fake.
