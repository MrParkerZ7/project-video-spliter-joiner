## Concept
Apply the T-053 tokens across every screen so the whole app looks like the redesign — dark panels, gold accents, rounded corners — with the UX/UI Reviewer confirming compliance.

## Design
- Restyle each view to reference the token brushes/radii/styles (no hardcoded greys/whites):
  - **`MainWindow.xaml`** — dark window bg (`BgBrush`), themed `TabControl` (Split/Join) with gold-accented selected tab.
  - **`PlayerView.xaml`** — video area `VideoBgBrush #000` in a rounded `SurfaceBrush` frame with the `AccentMuted` border; transport row on `Surface2`; **play/pause = accent (gold)**; scrub `Slider` gold thumb/track; jog buttons themed; the "preview unavailable" + status/ETA text in token colors.
  - **`TimelineView.xaml`** — track on `Surface2`; **playhead + cut-marker ticks = `AccentBrush` gold** (matches the mockup's gold pins); rounded.
  - **`SplitView.xaml`** — markers list, segment-select list, output, **Run = AccentButton (gold primary)**, Clear = secondary; GridSplitter grip visible; card surfaces rounded/dark.
  - **`JoinView.xaml`** — clip list, compat banner (keep green/red semantics but on dark), Run = accent, Clear all = secondary.
- **UX/UI Reviewer pass**: verify visual-hierarchy (primary/secondary/tertiary differentiated by ≥2 of form/size/weight/color-role/elevation), contrast/readability on dark (all text = theme tokens, none black), consistent gold accent usage, rounded/elevation consistency. Fix findings.
- Verify live via `app-run` (headless can't confirm the look — the reviewer + a real render on the user's desktop close it).

## Detail
- Preserve all behavior/bindings — this is styling only (swap brushes/styles, keep commands/bindings intact).
- Keep semantic colors where meaning matters (compat green/red, error red) but tune them for dark-bg contrast.
- Gold accent applied consistently: primary actions, cut pins, playhead, focus/selection.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Every view (MainWindow/Split/Join/Player/Timeline) references tokens — grep shows no leftover hardcoded greys/whites/black-text in the restyled views.
- [ ] Play button + Run are gold (accent); playhead + cut ticks are gold; panels dark + rounded; text uses theme tokens (readable on dark).
- [ ] UX/UI Reviewer pass done; findings fixed (visual-hierarchy + contrast + consistency).
- [ ] Build 0-warning; all prior tests green (styling → no logic/test change); app launches.
- Matrix — Required-Success: app looks like the redesign (dark+gold, rounded), verified by render/review. Boundary: long lists still readable; disabled buttons legible; error/compat colors visible on dark. Required-Fail: n/a.
