## Why / vision
G-017 applied the sample's dark+gold *palette* but not its *identity*: the sample is an **IBM Plex Mono** technical UI with a specific dense layout (file-info cards, taglines, badges, an estimated-result panel). To make the app look like the sample, adopt its typography, full color scale, tight radii, AND its component layout.

## Design spec (extracted from the sample bundle — grounded, not guessed)
- **Fonts:** `IBM Plex Mono` (primary — labels, values, mono readouts) + `IBM Plex Sans` (headings/body). The sample loads them from Google Fonts; the app must **bundle the .ttf/.otf** and reference via pack URI.
- **Colors (full set):** surfaces `#0a0b0d`·`#0d0f13`·`#0f1216`·`#101215`·`#12151a`·`#15181e`·`#181c22`·`#1a1d23`·`#1c2028`·`#20252e`·`#232935`; borders `#2a2e37`·`#3a4250`·`#42474f`; text `#e8eaef`·`#eef0f3`·`#9aa0ab`·`#8792a3`·`#767c88`; accent gold `#e0a83a` + hover `#f0bc55`; semantic green `#5fcf8e`/`#7cd6a0`, blue `#5b9cf0`, purple `#c77dff`; danger red (keep readable).
- **Radii:** 6–12px (tight); NOT 24px. **Type scale:** 8–18px (dense, mono at 11–13px).
- **Layout (from the sample's rendered labels):** header row "VideoSplitJoiner" + tagline "lossless · no re-encode" + a format badge ("HEVC · MKV"); Split: a **file-info card** (name + "matroska · 10:00 · 1.4 GB"), Timeline + Position, **"Cut markers"** section, **"Parts to export"** with **All / None** chips, output as **DIR / NAME** mono labels, a "Split into N parts" primary button, Clear; Join: clip list, **"Overwrite existing output"**, an **"Estimated result"** panel (Total duration / Approx. size), "Join N clips" button, Clear all.

## Decisions
- **D1 · Confirm from a RENDER first** — the labels/palette/fonts are extracted, but exact spacing/arrangement is a rendered React app. Before finalizing layout, render the sample (browser) OR have the user share a screenshot; align to it. (The extracted spec is enough to start; the render closes the last gap.)
- **D2 · Bundle the fonts** — download IBM Plex Mono + Sans, add to the project (`src/App/Fonts/`), set `Build Action: Resource`, reference via `pack://application:,,,/Fonts/#IBM Plex Mono`. Update the `AppFontFamily` token. (Note: IBM Plex is OFL-licensed — add attribution to THIRD-PARTY-NOTICES.)
- **D3 · Extend, don't restart** — refine the existing `Tokens.xaml`/`Controls.xaml` (from G-017) to the full spec, then restructure the views to the sample's layout. Keep all behavior/bindings.

## Risks
- **Exact layout needs a render** (D1) — without it, the arrangement is approximate; get a screenshot/browser render to nail spacing/order.
- Bundling + rendering a custom font in WPF (pack URI, fallback) + OFL attribution.
- This is a sizeable restyle/relayout (T-059 is L+) — the components (file-info card, estimated-result panel, badges, chips) are partly NEW UI, not just recoloring.

## Out of scope
Re-architecting the view-models, new features beyond what the sample shows, animations — later. This matches the sample's LOOK + LAYOUT.
