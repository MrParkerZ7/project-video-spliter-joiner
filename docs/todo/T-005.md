## Concept
Glue several videos into one via `-c copy` — lossless, instant — but only when their streams are truly concat-compatible; otherwise refuse with a clear, actionable reason rather than emit a broken file.

## Design
- `IJoinEngine` / `JoinEngine` in `Core/Join`, on `IFfmpegRunner` + `IMediaProbe`.
- `JoinAsync(JoinRequest { InputPaths[] (ordered), OutputPath }, IProgress, ct)`.
- Pre-flight: probe every input (T-003), compare codec/resolution/pix_fmt/timebase/audio params → `CompatReport { Compatible, Mismatches[] }`. Refuse if incompatible.
- Execute with the **concat demuxer**: write a temp `concat list.txt` → `ffmpeg -f concat -safe 0 -i list.txt -c copy <out>`. (Concat demuxer, not the concat protocol — works for mp4/mkv with `-c copy`.)

## Detail
- `CompatReport` names exactly what differs ("clip 2 is 1280x720, others are 1920x1080") so T-008 can show it.
- Handle path quoting inside the concat list (single-quote escaping).
- Optional `--force` is NOT offered in v1 (would need re-encode) — out of scope; refusal is the honest outcome.
- Progress mapped to summed input durations.

## Interfaces / contracts
- Consumes: probe/streams (T-003), runner (T-002).
- Produces: `JoinResult { OutputPath }` or a refusal `CompatReport` for T-008/T-009.
- Contract: no re-encode — asserts `-c copy`; never writes an output on an incompatible set.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Joining 3 same-codec/params clips yields one playable file, duration ≈ sum, no re-encode (`-c copy` asserted).
- [ ] Mismatched resolution/codec set is refused with a `CompatReport` naming the offending clip — no output written.
- [ ] Order is preserved as given.
- Matrix — Required-Success: compatible set → single joined file. Required-Fail: incompatible codecs/res/pix_fmt → refusal + reason, no partial file. Optional-Success: two identical clips → doubled. Boundary: single input (just copy/passthrough); empty list (rejected); paths with spaces/unicode in the concat list.

## Edge cases
One input; zero inputs; duplicate file listed twice; mismatched audio sample rate; container mismatch (mp4+mkv) — refuse or note.

## Dependencies
T-002 (runner), T-003 (probe for compat).

## Risks
Concat demuxer edge cases (timestamps, B-frames at boundaries) can cause A/V drift. Mitigation: smoke-probe the output + document known-compatible expectations.

## Out of scope
Re-encoding to force-compat (rejected v1); UI (T-008).
