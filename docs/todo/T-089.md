## Concept
Correct the T-087 layout. T-087 wrongly paired the **marker list** with Parts-to-export side by side. The user
actually wants: the **Cut markers** section (with the marker list) **full-width on TOP**, and **Position** (the
POSITION add-at-time field) + **Parts to export** **side by side BELOW it** — confirmed by the user against a
sketch 2026-07-19.

## Design (restructure the T-087 area in `SplitView.xaml`)
The current T-087 code is a 2-column `Grid` (`* | 12 | *`) with the **marker list** in column 0 and **Parts to
export** in column 1 (POSITION field wrapped inside column 0). Restructure to:
1. **Cut markers — full width, on top:** the "Cut markers" `SectionHeader` + the **"Add cut at playhead"** button
   + the **marker `ListBox`** as a single full-width block (NOT in a column).
2. **Below it, a 2-column `Grid`** (`* | small gap | *`, equal shared width — this is the "share horizontal size"):
   - **Column 0 — Position:** a small **"Position"** section header + the POSITION field row (POSITION label + the
     time `TextBox` bound to `NewMarkerPosition` + the "Add at time" button `AddMarkerCommand`). It's a compact
     control — top-align it in its column; the empty space below is fine.
   - **Column 1 — Parts to export:** the existing header Grid ("Parts to export" + "(N selected)" + All/None chips)
     + the segments `ListBox`.
3. Undo T-087's WrapPanel on the POSITION row if it's no longer needed at this width (a full column is wider than the
   old ~165px); keep it single-line if it fits, else leave the graceful wrap.
- **Re-parent, do NOT rewire** — every control/binding stays: `SetCutAtPlayheadCommand`, `NewMarkerPosition` +
  `AddMarkerCommand`, `SelectAll/NoSegmentsCommand`, per-part `IsSelected`, `SeekToMarkerCommand`/`RemoveMarkerCommand`,
  `SelectedSegmentCount`. Give the marker list (top) and parts list (bottom-right) sensible `MaxHeight`s.
