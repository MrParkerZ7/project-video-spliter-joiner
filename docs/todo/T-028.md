## Concept
The headline of the ask: move the playhead by set amounts to find the exact split point. Back/forward by 1s/5s/10s/20s/1m/5m, single-frame step, and jump-to-start/end — then drop a cut at that spot (the existing "Set cut at playhead").

## Design
- **`PlayerViewModel.SkipBy(TimeSpan delta)`** = `Scrub(Clamp(Position + delta, 0, Duration))` (relative seek over the existing `Seek`; D1). Provide a `SkipCommand` taking the delta (seconds) as a parameter, OR discrete commands per increment — pick the cleanest for XAML binding (a parameterized `RelayCommand<double seconds>` is fine). Guard: no-op when not `IsReady`.
- Increments (each direction): 1s, 5s, 10s, 20s, 60s, 300s. Plus `JumpToStartCommand` (seek 0) + `JumpToEndCommand` (seek Duration).
- **Frame-step (D2):** extend `IMediaPlayer` with `void StepFrame(int direction)` (+1 forward, −1 back). `FfmeMediaPlayer` → FFME `StepForward()`/`StepBackward()` (verify member names from the DLL); `NullMediaPlayer` no-op; test fake records the call. `PlayerViewModel.StepForwardCommand`/`StepBackCommand` call it (guard on IsReady).
- **UI (`PlayerView.xaml`):** a compact transport row of skip buttons around the existing play/pause — e.g. `|◄ ⏪5m 1m 20s 10s 5s 1s  ⏮frame  ▶/⏸  frame⏭  1s 5s 10s 20s 1m 5m⏩ ►|`. Group tight (small buttons, tooltips like "back 10s"); keep readable at the pane's min size. Labels can be compact ("−10s"/"+10s").

## Detail
- Clamp at both ends (skip past end → Duration; before start → 0). Report the resulting Position via the existing PositionText.
- Frame-step implies pausing first (FFME step works while paused) — pause if playing before stepping, or rely on FFME's step semantics; keep it correct.
- No change to split/join/marker logic — this only moves the playhead; the user then uses the existing Set-cut-at-playhead.

## Interfaces / contracts
- `IMediaPlayer` gains `StepFrame(int)` (update `FfmeMediaPlayer`, `NullMediaPlayer`, and the test fake). Volume/speed come in T-029.
- `PlayerViewModel` gains skip/step/jump commands; no other VM/contract change.

## Acceptance criteria + Case-Coverage Matrix
- [ ] `SkipBy(+10s)` from 5s → seeks to 15s (fake records Seek(15s)); `SkipBy(-10s)` from 5s → 0 (clamped); `SkipBy(+5m)` past end → Duration.
- [ ] Skip commands disabled when not IsReady; enabled after a file opens.
- [ ] `StepFrame(+1)`/`StepFrame(-1)` call the player (fake records direction); JumpToStart→0, JumpToEnd→Duration.
- [ ] Build 0-warning; existing tests green (fake IMediaPlayer updated for `StepFrame`); new SkipBy/step logic unit-tested.
