## Concept

Document the three surfaces G-058 changed: frame grabs that return the requested width (T-179), the hover
card's size and cut readout (T-180), and the picture refresh on apply (T-181).

## Acceptance criteria

- [ ] **`docs/USER_GUIDE.md`**, the card section:
      - no longer says *"320px wide"*;
      - says the picture shows at its own size, up to 640;
      - says what the two cut lines mean;

        one kept in `%LOCALAPPDATA%\VideoSplitJoiner\profile-thumbs\replaced` (the full path, so a
        replacement can be undone by hand);

      - Also say that on an existing library the card grows only as pictures are re-taken.
- [ ] **Specs:** SPEC-005 (T-179) and SPEC-007 (T-180/T-181) read as built, and the counts in
