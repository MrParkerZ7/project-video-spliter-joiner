## Concept
Render the loaded video's **audio waveform** as a band **above the timeline/mark bar** on the Split screen, so
the user can *see* the audio (speech vs silence, peaks) and place cut points at natural boundaries.

## Decisions (clarify round 1 — resolved)
- **D1 · Rendering:** **vector waveform aligned to the timeline** (extract peaks → themed WPF draw sharing the
  timeline's `0..duration` coords; crisp on resize). Not an ffmpeg `showwavespic` raster.
- **D2 · Interaction:** **fused with the timeline** — playhead across the wave, markers aligned, click-to-seek.
- **D3 · Scope:** **Split screen only.**
- Baked defaults: mono mixdown · background+cached extraction on load · no-audio → hidden.

Full model (Core `IWaveformService`, peak extraction, `TimelineView` band, edge cases, D-001/G-030 composition):

## Current state (verified)
- The "mark bar" is `TimelineView` (`SplitView.xaml` Grid.Row=2) — a 34px `Track` canvas with the playhead +
  cut-marker ticks drawn in code-behind, click-to-seek via `OnTrackClicked`. `PlayerView` is Row 0.
- **No audio/waveform/peak infra exists** — the app only reads audio *metadata* (codec/sample-rate/channels via
  ffprobe, for join-compat). Extracting + visualizing audio amplitude is new.

## Design direction (to confirm in clarify)
A waveform band directly above the timeline, **sharing the timeline's 0..duration coordinate system** so the
playhead and cut markers line up with the audio. Amplitude extracted from the video's audio (mono mixdown),
computed in the background on load + cached (like the keyframe scan). Forks below.

## Sensible defaults (baked unless changed)
- **Audio source:** mono mixdown of all audio tracks (standard waveform).
- **When computed:** background on load, cached + downsampled (large files don't block); parallels the keyframe scan.
- **No audio track:** hide the band (or a flat "no audio" line) — never an error.

## Out of scope (initial)
Automatic silence-detection / auto-cut-at-silence (a separate feature); per-frequency spectrogram; editing audio.
This is a **visual** waveform aid for manual cut placement.
