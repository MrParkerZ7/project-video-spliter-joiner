## Concept
Make the keyframe index itself fast. Today `GetKeyframesAsync` uses `-skip_frame nokey` (a frame-level decode-side scan). Reading keyframe **packets** at the demux layer is much cheaper and yields the same keyframe timestamps.

## Design
- In `src/Core/Media/MediaProbe.GetKeyframesAsync`, replace the query:
  - FROM: `ffprobe -skip_frame nokey -show_entries frame=pts_time,best_effort_timestamp_time,key_frame,media_type -print_format json`
  - TO: `ffprobe -select_streams v:0 -show_packets -show_entries packet=pts_time,dts_time,flags -print_format json` → keep packets whose `flags` contain `K` (keyframe marker); use `pts_time` (fall back to `dts_time`) as the timestamp.
- Demux-only (no frame decoding) → substantially faster on long/4K files. Output stays a **sorted, distinct `IReadOnlyList<TimeSpan>`** — identical contract; snap + cache unchanged.
- **Fallback:** if the packet query yields zero keyframes (odd container/flag formatting), fall back to the old `-skip_frame nokey` frame scan so we never regress correctness. Log which path was used.

## Detail
- Parse the packet `flags` string for `K` (ffprobe prints e.g. `K__` / `K_` for keyframe packets). Be robust to whitespace/underscores.
- Keep the per-file cache (path+mtime+length) exactly as-is.
- Measure before/after on a large fixture (reuse the 4K fixture pattern from T-024, or a longer 1080p clip): report the keyframe-scan time old-query vs new-query.

## Interfaces / contracts
- No signature change — `GetKeyframesAsync` returns the same sorted-distinct timestamps. Internal query only. Snap (`SnapToNearestKeyframe`) + `AverageGop` unchanged.

## Acceptance criteria + Case-Coverage Matrix
- [ ] `GetKeyframesAsync` (new packet query) returns the same keyframe set as the old frame query on the synthetic fixtures (assert equality/near-equality within tolerance on a known-GOP fixture — e.g. 1s-GOP → keyframes at whole seconds).
- [ ] Measurably faster on a large/long fixture (report old vs new ms).
- [ ] Fallback to the frame scan when packets yield nothing (unit-test the fallback path with a fake runner returning empty packets).
- [ ] Cache still serves the second call without a re-scan.
- [ ] Build 0-warning; existing probe/snap/split tests green.
- Matrix — Required-Success: packet query → correct keyframes, faster. Required-Fail: empty packets → frame-scan fallback → still correct. Boundary: single-keyframe file; VFR; container where flags differ.

## Dependencies
None (internal query swap). Independent of T-030; serialized on the shared MediaProbe/tests tree.

## Risks
Packet-flag format variance across containers → the fallback guarantees correctness; keep the known-GOP equality test to catch a bad parse.

## Out of scope
Non-blocking load wiring (T-030); on-disk persistent index; docs (T-032).
