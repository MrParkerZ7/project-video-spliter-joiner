## Concept
The split workflow surface: open a video, see its timeline, add/remove/edit cut markers by hand OR run auto-detect and accept/adjust the ranked candidates, then split — with the keyframe-snap made visible so there are no surprises.

## Design
- WPF `SplitView` + `SplitViewModel` binding to `ISplitEngine` (T-004), `ISplitPointDetector` (T-006), `IMediaProbe` (T-003).
- UI Designer sets the visual-hierarchy/token model first (levels differentiated by ≥2 of form/size/weight/color/elevation) before build.
- Timeline control: scrubber + keyframe density hint + draggable cut markers; each marker shows its snapped time + delta ("cut requested 01:23.4 → snaps to 01:22.0").
- "Auto-detect" button → runs detector, overlays ranked candidates (color-coded by Kind), user checks the ones to keep → they become markers.

## Detail
- Load via file picker + drag-drop; show MediaInfo (duration, codec, keyframe density warning when GOP is coarse).
- Marker list panel (add/edit/remove; snap-preview per marker).
- Output dir + naming pattern controls; overwrite guard.
- Run → progress bar (from T-004/T-009) + cancel; on done, show `SplitResult` (segments + actual snapped points), open-folder button.

## Interfaces / contracts
- Consumes: `SplitEngine.SplitAsync`, `SplitPointDetector.DetectAsync`, `MediaProbe`.
- Produces: no engine contract — it's the composition surface; hands a `SplitRequest` to the engine and renders `SplitResult`.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Load a file → timeline + info render; keyframe-coarse files show a warning.
- [ ] Add manual markers + run → segments produced; snapped time shown per marker before + after.
- [ ] Auto-detect → candidates overlaid + rankable + selectable → selected become cuts.
- [ ] Long split shows progress + cancels cleanly.
- Matrix (UI/action coverage per PROMPT_TESTING § Action Coverage) — every control (load, add-marker, edit-marker, remove-marker, auto-detect, select-candidate, choose-output, run, cancel, open-folder) has a smoke/interaction test. Required-Fail: run with zero markers → disabled/prompted; invalid output dir → inline error. Boundary: file with no keyframes-coarse warning; detect returns empty → friendly "no candidates found".

## Edge cases
No file loaded (run disabled); detect returns empty; cancel mid-run; extremely long timeline (virtualize).

## Dependencies
T-001 (shell), T-004 (split), T-006 (detect), T-003 (info) — via T-004/T-006.

## Risks
Timeline UX complexity. Mitigation: MVP timeline (list + simple scrubber) first; polish later.

## Out of scope
