## Concept
Replace the layout-toggle caption button's plain single-rectangle icon with a **two-pane split glyph** that
depicts the actual layout — so the button reads unmistakably as a horizontal↔vertical layout toggle. Keeps the
sealed D-001 D5 convention (the icon shows the mode it will switch **to**).

## Design (grounded — pure XAML geometry swap)
- **File:** `src/App/Themes/Controls.xaml` — the two geometry resources used by the `LayoutToggleButton` in
  `MainWindow.xaml` (swapped by a `DataTrigger` on `IsVertical`, tooltip via `LayoutToggleTooltip`). Today they are
  single `RectangleGeometry`:
  - `LayoutVerticalCaptionGeometry` = `Rect="2.5,0.5,6,10"` (tall rect, shown while **horizontal** → "switch to vertical")
  - `LayoutHorizontalCaptionGeometry` = `Rect="0.5,2.5,10,6"` (wide rect, shown while **vertical** → "switch to horizontal")
- **Replace each with a two-pane `GeometryGroup`** (two stroked rect outlines with a ~2px gap), on the same
  pixel-aligned ~11×11 field (`.5` offsets, 1px stroke), matching the G-029 caption-icon style (stroked outline,
  `TextPrimaryBrush`, gold on hover, `SnapsToDevicePixels`/`UseLayoutRounding`):
  - **`LayoutVerticalCaptionGeometry`** (shown while HORIZONTAL, target = vertical) → **two STACKED panes**:
    top `RectangleGeometry Rect="0.5,0.5,10,4"` + bottom `Rect="0.5,6.5,10,4"`.
  - **`LayoutHorizontalCaptionGeometry`** (shown while VERTICAL, target = horizontal) → **two SIDE-BY-SIDE panes**:
    left `RectangleGeometry Rect="0.5,0.5,4,10"` + right `Rect="6.5,0.5,4,10"`.
  - `Path.Data` accepts a `GeometryGroup`; the existing `Path` stroke/hover triggers + the `DataTrigger` swap +
    tooltip are unchanged. (Exact rects are a starting point — nudge for crisp 1px + visual balance.)
- **No VM / logic / behavior change** — only the two icon geometries. `IsVertical`/`ToggleLayoutCommand`/tooltip/
  the swap all stay as built in G-032.

## Acceptance criteria + Case-Coverage Matrix
- [ ] While horizontal, the toggle shows **two stacked panes**; while vertical, **two side-by-side panes** (target mode, per D5).
- [ ] Crisp 1px stroke at 100% + 150% DPI; `TextPrimaryBrush`, gold on hover (matches the other caption icons); swaps live on toggle.
- [ ] Tooltip + `ToggleLayoutCommand` behavior unchanged; both screens still flip.
- [ ] Build 0-warning; full suite green (pure geometry — the existing `MainViewModelLayoutToggle` tests stay green; no new tests needed unless a converter is added).
- Matrix — Success: icon reads as a layout toggle in both modes. Boundary: 150% DPI crispness; hover contrast; maximized (caption unaffected). Required-Fail: none. (Exact look = app-run/user-verified.)

## Dependencies
None. Refines G-032 (vertical-mode toggle).

## Risks
`GeometryGroup` as `Path.Data` + keeping the 1px stroke crisp (pixel-aligned rects). Don't disturb the min/max/close
caption icons or the toggle's command/tooltip wiring.

## Out of scope
Changing the toggle's position/behavior; animating the swap; other caption icons.
