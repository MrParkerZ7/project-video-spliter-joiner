## Concept
Find natural cut boundaries automatically so the user doesn't scrub: detect fade-to-black, fade-to-white, and hard scene changes, then present a RANKED list of candidate timestamps (D3). Detection only decodes frames — it never re-encodes.

## Design
- `ISplitPointDetector` / `SplitPointDetector` in `Core/Detect`, on `IFfmpegRunner` + `IMediaProbe`.
- `DetectAsync(path, DetectOptions, IProgress, ct)` runs a single decode pass with combined filters and parses stderr:
  - Black: `blackdetect=d=<minDur>:pic_th=<0..1>` → `black_start/black_end`.
  - White: invert-luma or `signalstats` YAVG threshold near max → white intervals.
  - Scene: `scdet=threshold=<n>` (or `select='gt(scene,<t>)'`) → scene-change scores.
- Merge overlapping detections; map each candidate to nearest keyframe (T-003) since the eventual cut snaps anyway.

## Detail
- `Candidate { Time, SnappedTime, Kind (Black|White|Scene), Score, Rank }`.
- Ranking: normalize per-kind scores → combined confidence; black/white fades rank above bare scene-score unless scene score is very high. Deduplicate candidates within a small time window.
- `DetectOptions { EnableBlack, EnableWhite, EnableScene, MinBlackDuration, SceneThreshold, MaxCandidates }` (defaults reasonable; UI exposes a few).
- One decode pass for all three filters where feasible (perf); progress mapped to duration.

## Interfaces / contracts
- Consumes: runner (T-002 via probe), keyframe snap (T-003).
- Produces: ranked `IReadOnlyList<Candidate>` for T-007 (UI presents accept/adjust) — the UI, not the detector, decides final cuts.
- Contract: pure read/decode — no output files, no re-encode.

## Acceptance criteria + Case-Coverage Matrix
- [ ] On a fixture with a known fade-to-black at ~t, a Black candidate appears within tolerance.
- [ ] White fade + a hard scene cut are each detected and Kind-tagged.
- [ ] Candidates are ranked (highest confidence first) and snapped to keyframes.
- [ ] Busy footage with no fades yields scene candidates but does not error/hang.
- Matrix — Required-Success: video with black/white/scene events → correct Kind-tagged ranked candidates. Required-Fail: unreadable file → typed error (shared with T-003). Optional: thresholds tuned via options change count sensibly. Boundary: all-black clip; no-event clip (empty candidate list is valid, not an error); very short clip.

## Edge cases
Clip with zero detectable events (return empty, not error); extremely long clip (progress + cancel); over-detection on high-motion footage (ranking + MaxCandidates cap).

## Dependencies
T-003 (probe + snap), T-002 (runner).

## Risks
scdet over-detects on busy content. Mitigation: threshold defaults + ranking + user-review gate in T-007; cap candidates.

## Out of scope
Actually performing the split (T-004); UI presentation (T-007).
