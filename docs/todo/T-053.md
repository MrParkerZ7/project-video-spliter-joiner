## Concept
The token foundation for the redesign: a WPF ResourceDictionary holding the palette, radii, typography, spacing, and elevation as named resources, plus base styles for the common controls — so every view themes by referencing tokens, never hardcoded hex.

## Design
- **UI Designer FIRST** (per the app-UI restyle rule): render the mockup HTML (`docs/design/references/2026-07-18_redesign-standalone.html`) in a browser to confirm exact colors/spacing/typography/component shapes, THEN author the tokens. If a browser render isn't available, ask the user for a screenshot; anchor on the extracted palette (below) meanwhile.
- **`src/App/Themes/Tokens.xaml`** (ResourceDictionary, merged in `App.xaml`):
  - Brushes: `BgBrush #0d0f13`, `SurfaceBrush #15181e`, `Surface2Brush #1a1e25`, `VideoBgBrush #000`, `AccentBrush #e0a83a`, `AccentMutedBrush` (#e0a83a @ ~25%), `TextPrimaryBrush` (~#EDEDED), `TextMutedBrush` (~#9AA0A8), `BorderBrush`, `DangerBrush` (keep the error red).
  - `CornerRadius`: `RadiusSm` (8), `RadiusMd` (12), `RadiusLg` (24). Spacing doubles. Type: font family + size scale (`FontSizeTitle/Body/Small`, weights).
- **Base styles** (implicit or keyed) for the controls the app uses so they look themed: `Button` (default + an `AccentButton` variant for primary/Run/gold), `Slider` (gold thumb/track — the scrub + volume), `CheckBox` (segments/mute), `ComboBox` (speed), `TabControl`/`TabItem` (Split/Join), `ProgressBar` (gold), `TextBox`/`TextBlock` (text tokens), `ListBox`/`ListBoxItem` (markers/segments/join list), `GridSplitter` (visible grip).
- Establish visual-hierarchy: primary (Run/accent) vs secondary (Clear/Stop) vs tertiary — differentiated by ≥2 of form/size/weight/color-role/elevation, not tint alone.

## Detail
- Tokens only in T-053; applying them across the actual views is T-054 (but wiring the merged dictionary + a couple of proof styles here is fine).
- Keep the existing error/danger styling legible on dark (don't lose the red error affordance).
- No behavior/logic change — pure resources + styles.
