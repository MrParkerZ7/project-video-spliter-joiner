# D-004 — Bulk Cut tab (batch intro + optional-outro trim)

**Board index for the design.** Full spec: [`../design/D-004/README.md`](../design/D-004/README.md) ·
flow + edge matrix: [`../design/D-004/core-flow.md`](../design/D-004/core-flow.md).

## Snapshot
- **What:** a 3rd tab "Bulk Cut" — batch-trim the intro (+ optional outro) off many videos, keeping the middle,
  stream-copy + keyframe-snapped. Output `<name>_trimmed<ext>` beside each source; originals kept.
- **How (reuse):** a bulk trim = a Split keeping ONE middle segment. Reuses `SplitEngine.SplitAsync` /
  `SplitRequest` / `MediaProbe` snap / `CutMarkerViewModel` (×2 handles/row) / `OperationViewModel` (per-row + aggregate)
  / Join's list scaffold / `IThumbnailService`. New: `BulkCutViewModel`, `BulkItemViewModel`, `BulkCutView`, an optional
  Core `BulkTrimEngine`+`KeptSegmentSelector`, and one new token `DropScrimBrush`.
- **UI:** per-row dual-handle scrub bar (gold intro-end `▸` top-cap · blue outro-start `◂` bottom-cap · gold keep-span
  glow · scrimmed dropped spans); apply-to-all; the four reused lifecycle surfaces; taskbar/title via the aggregate op.

## Clarified decisions (locked)
1. Cut points = **visual per-video + apply-to-all**.
2. Scope = **intro + optional outro** (keep the middle; outro optional ⇒ keep→EOF).
3. Output = **same folder, `_trimmed` suffix, originals kept**.
