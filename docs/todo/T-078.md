## Concept
Hovering the scrub bar shows a small frame thumbnail at the hovered time, following the cursor, with a time label — sourced from the T-077 service, debounced/coalesced so it stays smooth, cleaned up on load/clear.

## Design
### VM (WPF-free — extend `PlayerViewModel` or a new `ThumbnailPreviewViewModel`)
- Inputs: current `InputPath`, `Duration`, and a hovered fraction/time from the view.
- Exposes: `HoverTime` (TimeSpan), `HoverThumbnailSource` (an image the view can bind — keep the VM WPF-free by exposing a temp **path** `string?` and letting the view load it, OR expose a frozen `ImageSource` from the App layer; prefer path-in-VM + view loads/freezes), `IsThumbnailVisible` (bool), `HoverOffsetX` (double, for popup placement).
- **Debounce** hover updates (~60ms settle) before calling `IThumbnailService.GetThumbnailAsync`; **coalesce** (latest hover wins, cancel prior); update `HoverThumbnailSource` when the grab resolves for the still-current time. Off the UI thread; marshal the result back.
- Clear/hide on `MouseLeave`, on new load, and on `Clear()`/`Unload()`; call the service's `Clear` to sweep temp files.

### View (`PlayerView.xaml` + code-behind)
- On `ScrubSlider` `MouseMove`: compute hovered fraction = `e.GetPosition(track).X / track.ActualWidth` (guard width ≤ 0), → time = fraction × duration; push to the VM (`HoverTime`/`HoverOffsetX`). `MouseEnter`/`MouseLeave` toggle visibility.
- A `Popup` (or an overlay `Border`) anchored above the slider, `HorizontalOffset` = cursor X, containing an `Image` (the thumbnail, ~160px) + a `mm:ss` `TextBlock` label, styled with the IBM Plex tokens (dark surface, tight radius, subtle border). Load the temp jpg into a **frozen** `BitmapImage` (cross-thread safe; `BitmapCacheOption.OnLoad` so the file isn't locked).
- Don't interfere with click-to-seek (G-028) or drag scrub — hover preview is display-only; clicking still seeks.

## Acceptance criteria + Case-Coverage Matrix
- [ ] Hovering the scrub bar shows a thumbnail of the frame at the hovered time, following the cursor, with a time label.
- [ ] Sweeping across the bar stays smooth — few ffmpeg processes (debounced + coalesced + cached), UI never blocks.
- [ ] Leaving the bar hides the preview; a failed grab shows nothing (no crash, no stuck popup).
- [ ] New load / Clear hides the preview and clears temp thumbnails (no leak).
- [ ] Click-to-seek + drag scrub still work (not intercepted by the hover handler).
- [ ] Build 0-warning; suite green + any VM tests (debounce/coalesce/visibility logic with a fake `IThumbnailService`).
- [ ] UX/UI review: popup placement (doesn't clip at bar ends), size, label legibility, dark-theme styling.
- Matrix — Required-Success: hover mid-bar → correct-time thumbnail near cursor. Boundary: hover at extreme left/right (popup clamps on-screen), rapid sweep (coalesced), very short/very long video, hover with no file (no popup). Required-Fail: none. (Exact feel = app-run/user-verified.)
